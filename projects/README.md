# Projects Snippets

Each file in this folder represents a personal, academic, or side project that demonstrates skills outside of formal employment.

## When to Use
Include a Projects section on a resume when:
- The job description requires skills not covered by professional experience
- The role aligns with hobby/self-taught domains
- Personal work provides concrete proof of capability that bridges a gap

## File Naming Convention
`YYYY-short-project-name.md` — e.g., `2023-brick-breaker-unity.md`

## File Format

```markdown
---
title: [Project Name]
type: [Game / Simulation / Tool / Hardware / Other]
year: [YYYY or YYYY–YYYY]
technologies: [comma-separated list]
tags: [relevant skill/domain tags for ATS matching]
---

## Summary
[1-2 sentences: what it is, what you built, what it demonstrates]

## Highlights
- [Specific technical detail or capability demonstrated]
- [Any measurable outcome, complexity, or notable design decision]

## Links
[GitHub URL, itch.io, video, etc. — or omit if not publicly available]
```
