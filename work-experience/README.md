# Work Experience Snippets

Each file in this folder represents a single role or work experience entry.

## File Naming Convention
`YYYY-COMPANYNAME-title.md` — e.g., `2023-acme-senior-engineer.md`

## File Format

```markdown
---
company: Acme Corp
title: Senior Software Engineer
start: 2021-03
end: 2023-11
location: Remote
tags: [leadership, cloud, python, agile]
---

## Summary
Brief 1-2 sentence overview of the role and its impact.

## Responsibilities
- Led a team of 5 engineers building microservices on AWS
- Reduced deployment time by 40% via CI/CD pipeline improvements

## Achievements
- Delivered Project X 2 months ahead of schedule
- Promoted to tech lead within 18 months
```

## Usage
The resume builder skill will pull relevant entries based on job description keywords matched against `tags`.
