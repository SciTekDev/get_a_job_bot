# Resume Workspace — 2026

A structured snippet library for generating tailored resumes for job postings.

## Quick Start

**Upstream skills:** Skills can be obtained manually from [GitHub's Awesome Copilot collection](https://github.com/github/awesome-copilot) and [Anthropic's skills repository](https://github.com/anthropics/skills). To fetch the latest `docx`, `pdf`, `skill-creator`, and `doc-coauthoring` skills from Anthropic into this workspace, run `npm run download` (requires Node.js 18 or newer). Check each skill's license before copying or redistributing it; some have additional restrictions.

> **First time here?** Run `/extract-snippets` with your existing resume(s) to bootstrap the snippet library before starting any applications.

**Per-application workflow:**

1. **Fill in your contact info** *(once)*: [`.github/skills/resume-builder/assets/contact.md`](.github/skills/resume-builder/assets/contact.md)
2. **Bootstrap your snippet library** *(once)*: Run `/extract-snippets` with your existing resume — populates all snippet folders automatically.
3. **Import a job posting**: Run `/import-job` and paste the job description — creates the application folder automatically.
4. **Generate a resume**: Run `/resume-builder` pointed at the `job_description.md` — saves `resume.md` in the same folder.
5. **Generate a cover letter**: Run `/cover-letter` pointed at the `job_description.md` — saves `cover_letter.md` in the same folder.
6. **Prep for a role** *(optional)*: Use the **Interview Prep** agent with the `job_description.md` to find gaps and backfill snippets.

**Recommended flow per application:** `/import-job` → `/resume-builder` → `/cover-letter`

## Application Folder Structure

```
job_applications/
└── 2026-06-24_Acme-Corp_Senior-Engineer/
    ├── job_description.md   ← paste JD here
    ├── resume.md            ← generated by /resume-builder
    └── cover_letter.md      ← generated by /cover-letter
```

## Snippet Folders

| Folder | Contents |
|--------|---------|
| [`work-experience/`](./work-experience/README.md) | One file per role |
| [`certifications/`](./certifications/README.md) | One file per certification |
| [`accomplishments/`](./accomplishments/README.md) | Awards, recognitions, key achievements |
| [`skills/`](./skills/README.md) | Skill categories grouped by domain |
| [`education/`](./education/README.md) | Degrees and educational credentials |

## AI Tools

### Prompts (type `/` in chat)

| Prompt | How to Invoke | Purpose |
|--------|--------------|---------|
| Import Job | `/import-job [paste JD]` | Creates the application folder and saves `job_description.md` with structured frontmatter |
| Resume Builder | `/resume-builder [path or JD]` | Assembles a tailored resume from snippets; saves `resume.md` in the application folder |
| Cover Letter | `/cover-letter [path or JD]` | Writes a tailored cover letter; saves `cover_letter.md` in the application folder |
| Extract Snippets | `/extract-snippets [path or paste resume]` | Parses an existing resume and extracts structured snippets into the snippet library |

### Agents (select from agent picker)

| Agent | Purpose |
|-------|---------|
| **Interview Prep** | Analyzes a JD against your snippets, identifies gaps, and interviews you to backfill missing content |
