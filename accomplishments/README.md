# Accomplishments Snippets

Each file in this folder represents a notable accomplishment, award, or recognition.

## File Naming Convention
`YYYY-short-description.md` — e.g., `2022-employee-of-year.md`

## File Format

```markdown
---
title: Employee of the Year
context: Acme Corp
year: 2022
tags: [leadership, performance, recognition]
---

## Description
Concise description of the accomplishment and its impact. Use metrics where possible.

**Impact**: Increased team throughput by 30% through process improvements.
```

## Usage
The resume builder skill will select accomplishments that align with priorities in the target job description.
