# Skills Snippets

Each file in this folder represents a skill category or technology group.

## File Naming Convention
`category-name.md` — e.g., `cloud-platforms.md`, `programming-languages.md`

## File Format

```markdown
---
category: Cloud Platforms
tags: [cloud, aws, azure, gcp, infrastructure]
---

## Skills
- **AWS** — EC2, S3, Lambda, RDS, CloudFormation (5 years)
- **Azure** — App Services, Azure DevOps, AKS (2 years)
- **GCP** — BigQuery, Cloud Run (1 year)
```

## Usage
The resume builder skill pulls the most relevant skill categories based on the job description keywords.
