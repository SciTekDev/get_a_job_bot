# Job Applications

Each subfolder represents a single job application. All generated documents for that application live together in the same folder.

## Folder Naming Convention
`YYYY-MM-DD_[Company]_[Role]` — e.g., `2026-06-24_Acme-Corp_Senior-Engineer`

## Folder Structure

```
job_applications/
└── 2026-06-24_Acme-Corp_Senior-Engineer/
    ├── job_description.md     ← Paste the JD here first
    ├── resume.md              ← Generated by /resume-builder
    └── cover_letter.md        ← Generated by /cover-letter
```

## Workflow

1. **Create a new application folder** following the naming convention above.
2. **Create `job_description.md`** inside it — paste the full job description (see template below).
3. **Run `/resume-builder`** — point it at the `job_description.md` file; it saves `resume.md` in the same folder.
4. **Run `/cover-letter`** — point it at the `job_description.md` file; it saves `cover_letter.md` in the same folder.
5. *(Optional)* Use the **Interview Prep** agent with the same `job_description.md` to backfill any snippet gaps.

## Job Description Template

When creating `job_description.md`, use this format:

```markdown
---
company: Acme Corp
role: Senior Software Engineer
date_applied:
source: LinkedIn
status: applied   # applied | interviewing | offer | rejected | withdrawn
---

<!-- Paste the full job description text below this line -->
```
