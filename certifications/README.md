# Certifications Snippets

Each file in this folder represents a single certification or credential.

## File Naming Convention
`YYYY-cert-name.md` — e.g., `2023-aws-solutions-architect.md`

## File Format

```markdown
---
name: AWS Certified Solutions Architect – Associate
issuer: Amazon Web Services
issued: 2023-04
expires: 2026-04
credential_id: ABC123XYZ
tags: [cloud, aws, architecture, infrastructure]
---

## Description
Brief description of what this certification validates.
```

## Usage
The resume builder skill will include certifications relevant to the target job description.
