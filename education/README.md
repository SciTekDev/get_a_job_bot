# Education Snippets

Each file in this folder represents a degree, diploma, or educational credential.

## File Naming Convention
`YYYY-institution-degree.md` — e.g., `2010-state-university-bs-computer-science.md`

## File Format

```markdown
---
institution: State University
degree: Bachelor of Science
field: Computer Science
graduated: 2010-05
gpa: 3.7
tags: [computer science, engineering, mathematics]
---

## Highlights
- Dean's List — 4 semesters
- Senior capstone: Distributed systems fault-tolerance research
```

## Usage
The resume builder skill includes education entries relevant to the target role.
